# ROTATION/INVERSION HYPOTHESIS: Testing Spatial Geometry vs. Cardinal Direction Mismatch
**Date**: September 24, 2026
**Hypothesis**: Could BoM author have used Moll (or other Lahontan-derived) maps with ROTATED or INVERTED cardinal directions, matching SPATIAL RELATIONSHIPS even if compass directions don't align?

---

## RESEARCH DESIGN

### Core Question
If the BoM's spatial geography (river flows E-W, narrow passage N-S, territorial divisions) doesn't match Moll maps in STANDARD orientation, does it match when the map is:
- **Rotated 90° clockwise** (East becomes North)?
- **Rotated 90° counterclockwise** (West becomes North)?
- **Rotated 180°** (South becomes North)?
- **Cardinal directions inverted** (treating North as South, East as West)?

### Test Framework

**BoM Geographic Requirements** (from CARTOGRAPHY_FEATURE_ANALYSIS):
1. River Sidon flows **E-W** (east to west)
2. River serves as **political dividing line**
3. Narrow neck of land: ~1.5 days' journey
4. Narrow neck connects Land **Southward** (below) to Land **Northward** (above)
5. Seas on **North, South, East, West** sides
6. Wilderness barriers between settled zones
7. Territorial divisions (east/west coast control, central interior control)

**Map Features to Check After Rotation**:
- Does a major river now appear to flow E-W?
- Does the narrow passage now run N-S (perpendicular to river)?
- Are territorial divisions now oriented N-S (Land North vs. South)?
- Do coastal cities align with rotated geography?
- Does the peninsula-like shape now match?

## ROTATION TEST 1: 90-DEGREE CLOCKWISE ROTATION

### Geometric Effect
- Original North → becomes East
- Original East → becomes South
- Original South → becomes West
- Original West → becomes North

### Expected Changes in Moll Map
**Before rotation (standard N-at-top orientation)**:
- Rivers flow generally N-S or have branches flowing in multiple directions
- Territories distributed E-W along coast
- Long River (from Lahontan) may flow SE-NW

**After 90° clockwise**:
- Rivers that flowed N-S now appear to flow E-W
- Territories that were E-W distributed now appear N-S distributed
- Any N-S oriented passage now appears E-W
- NE-SW features now appear E-W

### Analysis Target
Look specifically at:
1. Mississippi River system after rotation — does it now run E-W through center?
2. Great Lakes region after rotation — do they now form a N-S barrier?
3. Coastal settlement pattern after rotation — do they align with BoM's coastal-to-inland model?
4. Any narrow passages after rotation — do they now separate N-S regions?

## ROTATION TEST 2: 90-DEGREE COUNTERCLOCKWISE ROTATION

### Geometric Effect
- Original North → becomes West
- Original West → becomes South
- Original South → becomes East
- Original East → becomes North

### Expected Changes in Moll Map
**Before rotation**:
- (Same as Test 1)

**After 90° counterclockwise**:
- Rivers that flowed N-S now appear to flow W-E
- Territories shift in different direction than 90° clockwise
- Different subset of features align with BoM geography

### Analysis Target
Same as Test 1, but checking whether this rotation produces better or worse alignment than 90° clockwise.

## ROTATION TEST 3: 180-DEGREE ROTATION

### Geometric Effect
- Original North ↔ South (complete reversal)
- Original East ↔ West (complete reversal)
- All features horizontally AND vertically flipped

### Expected Changes in Moll Map
**Before rotation**:
- (Standard orientation)

**After 180°**:
- Rivers that flowed from upper-left to lower-right now flow from lower-left to upper-right
- "Land Northward" now appears at "South" position
- "Land Southward" now appears at "North" position
- All territories inverted

### Analysis Target
Check whether this inversion creates a mirror-image match to BoM geography:
1. Do rivers now flow the required direction?
2. Do territorial divisions now make sense?
3. Does the narrow passage now separate the right regions?

## TEST 4: INVERTED CARDINAL DIRECTIONS (COMPASS SWAP)

### Hypothesis Variant
Rather than rotating the actual map, what if the BoM author RECEIVED the map but MISREAD the cardinal directions? For example:
- Read the cartographer's "North" label as "South"
- Read "East" as "West"
- Used this inverted reading to describe Nephite geography

### Effect of Cardinal Inversion
**If treating N→S, S→N, E→W, W→E** (inverted):
- River flowing N-S becomes described as S-N (still N-S, just direction reference flipped)
- River flowing E-W becomes described as W-E (still E-W, just direction reference flipped)
- **Spatial relationships stay the same; only direction NAMING changes**

### Analysis Target
This is less about visual matching and more about whether the BoM author could have:
1. Seen a map with rivers flowing E-W
2. Intentionally or unintentionally inverted the compass references
3. Created internally consistent BoM geography using inverted compass labels
