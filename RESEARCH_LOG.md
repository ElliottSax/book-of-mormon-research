# Research Log

Living, dated record of what's been tested, what was found, and how confident
we should be about it. JSON reports in `reports/` are regenerated by
`bookcli.py report` and get overwritten each run; this file is the narrative
record that survives across sessions. Every finding below states its
baseline/null comparison and an explicit verdict — a raw similarity number
alone is not a finding in this project.

---

## 2026-08-23 — Toolkit rebuild, corpus fixes, and the Lahontan/Liahona correction

### What was broken, and what's fixed now

The toolkit existed but had never been committed to git and had several
live bugs undermining its own results:

- `corpus.py` never loaded the Aeneid control text at all (silently
  skipped in every comparison) — and separately, **all three files ever
  associated with "aeneid" in this repo turned out to be unusable**:
  `texts/aeneid.txt` was a saved archive.org error page, `texts/aeneid_dryden.txt`
  was a raw 504 Gateway Timeout page, and a stray root-level `aeneid.txt`
  — assumed valid — turned out to be Pope's translation of the **Iliad**
  (Gutenberg #6130), not the Aeneid at all. Fixed: sourced Dryden's real
  Aeneid translation (Gutenberg #228, 110,589 words), added
  `corpus.verify_text_integrity()` so a corrupted download can never again
  pass through silently (checks for HTML/error-page markers and a minimum
  word count).
- Two different, both-broken book-segmentation heuristics existed
  (`analysis.py`'s hardcoded "very approximate" character-offset slicing,
  and `bookcli.py`'s all-caps-heading detector) — confirmed broken: the
  sole real "Liahona" occurrence was misattributed to a `null` book bucket.
  Fixed: `segmenter.py` is a real parser built on the text's own Contents
  block and verse markers (chapter/verse numbers are printed explicitly in
  two coexisting formats), with a self-check that the total parsed verse
  count (6,598) falls in the canonical range (~6,300–6,700). Liahona now
  correctly attributes to **Alma 37**.
- `stylometry.liahona_term_counts()` used raw substring counting
  (`text.count("compass")`), which silently included "compassed" and
  "compassion" — inflating the Book of Mormon's reported "compass" count
  from **7** (the real navigational-device references) to **22**. Fixed
  with word-boundary regex matching.
- `scripts/textreuse.py` used naive 5-character shingles — analytically
  weak (common short substrings dominate regardless of real phrase reuse)
  — and had never actually been run against Lahontan; its Spalding output
  was never persisted to a report. Fixed: rewritten as word-level n-grams
  (default 6 words), run against both pairs, persisted to
  `reports/textreuse_bom_vs_spalding.json` and
  `reports/textreuse_bom_vs_lahontan.json`.
- `scripts/integrate_brave_pipeline.py` (a bridge to an unrelated video
  project) read report keys (`delta_distance`, `top_markers`) that don't
  exist in the real schema, silently producing an empty/wrong "successful"
  report. Deleted.
- Reproducibility bug: `bom_vs_spalding.json` (repo root) and
  `reports/authorship_analysis.json` disagreed on `emodern_density` for the
  identical comparison, because `stylometry.py` had its own redundant CLI
  that skipped `corpus.normalize_spacing()`. Fixed by deleting the
  redundant CLI (bookcli.py's `compare` subcommand is the one entry point
  now) and the stray file.
- Hand-rolled Soundex/NYSIIS were replaced with `jellyfish` (MIT,
  actively maintained) after a GitHub tools survey — the hand-rolled
  versions were plausible but unvalidated against the canonical algorithm
  definitions; `jellyfish` also adds Metaphone and Jaro-Winkler as
  additional independent signals for free.

New modules: `segmenter.py` (real book/chapter/verse structure),
`namesim.py` (name-derivation similarity with a mandatory chance-baseline
check — see below), `parody_hypotheses.py` (a citation-carrying claims
registry, kept separate from the scoring algorithm).

### Baseline stylometric numbers (with a working control text, finally)

| Pair | Cosine similarity | EModern/KJV-dialect density |
|---|---|---|
| BoM vs. Spalding manuscript | 0.8204 | BoM 0.0491 vs. Spalding 0.0024 (~20x) |
| BoM vs. Lahontan (complete text, see below) | 0.8933 | BoM 0.0491 vs. Lahontan ~0.0007 (~70x) |
| BoM vs. Aeneid (Dryden) — **control** | 0.8356 | — |

**Verdict:** the Aeneid control — a genuinely unrelated 17th-century poetic
translation — scores *between* Spalding and Lahontan on cosine similarity.
That means "Lahontan scores higher than Spalding" is not, by itself,
distinctive: an unrelated epic poem lands in the same range. Cosine
similarity on raw word frequency is picking up something like "both are
long, old-fashioned formal English prose/verse," not a specific stylistic
fingerprint. Treat these cosine numbers as weak evidence at best without
further work (e.g. a proper Burrows' Delta implementation — see Future Work).

### Onomasticon (proper-noun overlap), BoM vs. Lahontan

24 "shared proper nouns" after filtering Gutenberg-boilerplate artifacts
("com", "project" — an earlier pass hadn't filtered these). The list is
still weak: `adam, angola, ani, book, church, egyptians, eternal, father,
general, god, great, holy, jews, king, latter, lord, man, mary, new, peace,
red, son, spirit, supreme` — dominated by common English/theological
vocabulary, not distinctive names. **No genuinely rare, distinctive shared
proper name was found.** (A much earlier, buggy version of this same tool
had produced 154 "matches" that turned out to be sentence-initial common
words — a documented false-positive episode worth remembering as a caution
against trusting a first pass at this kind of matching.)

### Lahontan/Liahona: corrected finding (supersedes an earlier, wrong "zero lexical connection" result)

An earlier pass through this codebase concluded there was no lexical
evidence at all connecting Lahontan's text to the Liahona — "compass" and
"liahona" appearing zero times in `texts/lahontan_new_voyages.txt`. **That
conclusion was wrong**, for two compounding reasons surfaced when the
user's own much more extensive prior research (an ~81,000-word dossier,
`research-notes/liahona_dossier.docx`) was reviewed directly against the corpus:

1. **The corpus was missing an entire volume.** `texts/lahontan_new_voyages.txt`
   contained only Volume I of Lahontan's *New Voyages*. The specific
   passages the dossier's conceptual argument rests on are in **Volume
   II** (the Mémoires), which wasn't in the repo at all. Fixed: sourced
   both volumes of the Thwaites 1905 critical edition from archive.org
   (`newvoyagestonort01laho`, `newvoyagestonort02laho`) and replaced the
   old, edition-mismatched, Volume-I-only file with a consistent,
   complete two-volume text (269,330 words).
2. **OCR long-s misreads.** The scan renders non-word-final lowercase "s"
   as a long-s glyph, which OCR frequently misreads as "f" — so "compass"
   appears in the raw text as "compafs" or "compaff". A literal
   word-boundary search for "compass" (the fix applied after catching the
   *first* bug, the substring/compassion conflation) still returned **zero**
   hits purely from this artifact. Fixed: `stylometry.ocr_tolerant_pattern()`
   builds a regex tolerant of the s/f substitution at non-final positions.

**With both fixes and the complete text**, "compass" (OCR-tolerant, word
boundary) matches 26 times — but that count mixes three distinct senses
that a regex can't disambiguate automatically, so this was checked by
hand:

- **7 are the navigational-instrument sense** (the relevant one).
- 13 are the archaic verb "to compass" = to achieve/accomplish ("compass
  their end").
- 6 are the noun sense meaning "extent/range" ("within the compass of my
  own knowledge", "20 leagues in compass").

Of the 7 instrument-sense hits, one is a genuinely significant, specific,
quotable passage from Volume II (p. ~10305 in the OCR text):

> "The Savages believe that a Watch, a Compass, and a thousand other
> Machines are moved by Spirits; for your ignorant and clownish People
> form extravagant Ideas of every thing that surpasses their Imagination."

And a second, related passage (p. ~849):

> "They took my Graphometer for somewhat Divine, being unable to guess how
> we could know the distance of Places without measuring them by Cords or
> Rods, without there were some Supernatural Assistance."

**This is a real, specific, thematically-adjacent parallel** — a compass
(among other instruments) attributed spiritual/supernatural agency —
genuinely closer to the Liahona's faith-dependent operation (Alma 37:40:
"it worketh according to the faith... of him that sent them") than
anything found before Volume II was added. It should be treated as the
single most substantive data point this research thread currently has.

**Stay skeptical of the framing, though.** Lahontan's passage is a
mocking, skeptical European Enlightenment aside about "ignorant" native
peoples misattributing agency to unfamiliar technology — the opposite
tone from the Book of Mormon's own reverent, first-person narrative
treatment of the Liahona as a real, God-given instrument. Thematic
adjacency is not the same as narrative source material. No evidence has
been found that Joseph Smith, Solomon Spalding, or Sidney Rigdon actually
read this specific passage — availability (see below) is necessary but not
sufficient to establish influence.

`ball` remains a genuine null even with the complete text: all 26
occurrences are gunpowder/ammunition ("Powder and Ball"), a cannonball
simile, a watermelon simile, or descriptions of an indigenous ball game
(explicitly identified in the text as lacrosse) — none relate to a
guidance device. `director` returns 0 hits in the current (Thwaites)
edition (a different translation choice than the earlier, discarded
edition, which had one hit referring to Dutch West India Company
administrators — either way, unrelated to the Liahona).

**Access/availability (from the user's dossier, not independently
re-verified here):** Lahontan's English translation went through 20+
editions and is documented in Thomas Jefferson's library and the Library
Company of Philadelphia — but is explicitly **absent** from the one
library closest to Joseph Smith himself, the Manchester/Palmyra library,
per Robert Paul's 1982 study. This is a real, honestly-reported negative
finding, not a suppressed inconvenient fact — it materially weakens (without
eliminating) the availability argument for direct influence on Smith
specifically, though it doesn't address Spalding's or Rigdon's own,
separate, undetermined access.

**Phonetic/orthographic:** `namesim.py`'s chance-baseline check (Soundex +
NYSIIS + Metaphone + sequence/Jaro-Winkler similarity, scored against a
sample of Lahontan's own distinctive vocabulary) finds Liahona/Lahontan
*is* statistically distinguishable from chance (composite 0.336, z ≈ 3.8
against the baseline distribution — see `reports/authorship_analysis.json`
→ `parody_hypotheses`). Read this cautiously: this pair was hand-selected
specifically *because* it already looked similar, so there's no correction
here for that selection effect (the classic multiple-comparisons problem —
if you look at enough word pairs, some will look unusually similar by pure
chance, and the ones that do are exactly the ones that get proposed as
hypotheses). This number is evidence the orthographic resemblance is real
and non-trivial, not evidence of a causal connection.

**Bottom line for this thread:** upgraded from "no evidence found" to "one
specific, real, quotable conceptual parallel exists, in a text with
confirmed but geographically incomplete circulation, with unusually
strong-for-chance orthographic name similarity — and no confirmed reading
by any of the three candidate authors, and a real tonal mismatch in how
the source material frames the parallel." This is genuinely more
interesting than a null result, and genuinely short of a demonstrated
connection. The user's own dossier states its verdict as "no slam dunk
either way," and that remains accurate.

### The Mosiah-priority (dictation-order) angle

Raised mid-session: if the Book of Mormon was dictated Mosiah-through-Moroni
first and 1 Nephi-through-Words of Mormon last (to replace the lost 116
pages) — the well-supported "Mosiah priority" theory from manuscript
evidence (see Royal Skousen's Critical Text Project) — then *when* a term
was introduced relative to dictation order matters, not just where it
ends up in the final book order. `segmenter.by_dictation_batch()` was
added to test this directly:

| Term | First-dictated (Mosiah–Moroni) | Second-dictated (1 Nephi–Words of Mormon) |
|---|---|---|
| liahona | 1 (Alma) | 0 |
| director | 3 (Mosiah 1, Alma 37×2) | 0 |
| ball | 2 (Mosiah 1, Alma 37) | 8 (1 Nephi 16×7, 2 Nephi 5) |
| compass | 3 (Alma 37, instrument sense) | 4 (1 Nephi 18×2, 2 Nephi 5,7) |
| pointers | 0 | 1 (1 Nephi 16) |

**Observation:** "Liahona" and "director" appear *exclusively* in the
first-dictated material (Alma/Mosiah), while "pointers" appears
exclusively in the second-dictated material (1 Nephi), and "ball"/
"compass" appear in both. If Mosiah priority holds, this means: by the
time the author dictated the 1 Nephi narrative describing the object in
detail (dictated *after* Alma), they had already established the specific
name "Liahona" — via the Alma 37:38 gloss ("...our fathers called it
Liahona...") — yet chose not to use that name anywhere in the 1 Nephi
narrative chapters that actually describe the object being used (16, 18),
preferring "ball"/"compass"/"pointers" there instead. This is consistent
with (though doesn't prove) "Liahona" being a term introduced or coined
specifically for the Alma 37 aside, with the earlier-composed-in-the-
narrative-but-later-dictated 1 Nephi material never retrofitted to use it
consistently. **This is a testable, useful angle for the Spalding-theory
question the user raised** ("does Liahona's Alma-only distribution
indicate it wasn't in an original proto-text base level, if one existed")
— but it's circumstantial, not dispositive: the simpler explanation (an
author introducing a proper name once and using descriptive terms
elsewhere in narration, a completely ordinary stylistic choice) can't be
ruled out with this data alone. Flagged as a promising thread for further
work, not a conclusion.

## Lars Nielsen / "Kircherism" summary (background research, 2026-08-23)

Lars Nielsen's *How the Book of Mormon Came to Pass: The Second Greatest
Show on Earth* (2024, self-published) argues Book of Mormon names/motifs
are "Kircherisms" — wordplay/allusions derived from 17th-century Jesuit
polymath Athanasius Kircher, transmitted via a claimed chain: Kircher → a
Dartmouth Professor of Oriental Languages (100+ years later) → his student
Solomon Spalding → Sidney Rigdon → Joseph Smith. This is an elaboration
*on top of* the traditional Spalding-Rigdon authorship theory, which
mainstream Book of Mormon scholarship (including the user's own dossier,
independently) treats skeptically.

Specific claims: "Mormon" derived from a 1650 French satire *Le Parasite
Mormon: Histoire Comique* (about a real person, Montmaur; claims a
syllable swap mon-MOR→MOR-mon); "Nephi" derived from Kircher's "Barachias
Nephi" — used only in unpublished 1628–1632 letters to Pietro della Valle
(Vatican archives), while Kircher's *published* works instead say
"Abenephius the Arab", a sourcing discrepancy critics have flagged;
Liahona/compass claimed to derive from Kircher's "spiritual magnetism"
concept.

**Reception:** harshly negative from LDS apologetics — the Interpreter
Foundation's review, "The Flimsiest Show on Earth," states the theory has
"not even one iota of merit" and calls it "almost laughable," specifically
noting there is **no "magnetic" language anywhere in the actual Book of
Mormon text**, so the claimed Liahona/magnetism link is textually
unsupported on its face. Critical/ex-Mormon forums were similarly harsh
("utter nonsense"; one commenter called it "a grift, a parody of
scholarship" — this is the actual source of "parody" in the discourse:
**critics describing the low quality of Nielsen's own scholarship**, not a
claim that the Book of Mormon text itself is intentional satire). Some
curious/positive reception exists elsewhere (a Sunstone presentation,
some Reddit discussion treating it as work-in-progress).

**Relation to the user's Lahontan dossier:** the dossier independently
compares itself to Nielsen's methodology (Part XVIII.3) and argues that,
*measured by Nielsen's own evidentiary standard* (a specific, findable,
erudite intermediary with documented circulation), the Lahontan hypothesis
actually outperforms Nielsen's preferred source — Kircher has zero
documented Dartmouth library holdings, while Lahontan has confirmed
holdings in Jefferson's library and the Library Company of Philadelphia.
This is a fair internal-consistency point, though it compares two
unproven hypotheses' evidentiary quality against each other, not against
an actual demonstrated connection.

No published source (Nielsen's or otherwise) connects Lahontan to the
Liahona specifically — that thread is the user's own original research,
distinct from Nielsen's Kircher claims, and should continue to be treated
as such (see `parody_hypotheses.py`).

## What the user's existing dossier covers that this session didn't re-derive

The user's ~81,000-word research document (`research-notes/liahona_dossier.docx`)
is substantially larger and more developed than anything in this repo
before this session, and is unusually self-critical for this genre — it
already maintains a live claims-vs-evidence matrix, 18 red-team
objections with counters, 18 lettered "blind spots" (explicitly including
*"no statistical base rate / null hypothesis... the single load-bearing
empirical gap in the whole thesis"* — precisely the gap `namesim.py`'s
baseline check now addresses), and cites real primary/secondary sources
throughout (Thwaites, the BYU Book of Mormon Onomasticon, Skousen's
Critical Text Project, Sowerby's Jefferson-library catalog, plus
LDS-critical and LDS-apologetic secondary literature: Vogel, Brodie,
Palmer, Grunder, Ostler/Interpreter, FAIR, Quinn, Shalev, Davis). It also
covers several threads not brought into this codebase yet:

- Josephus's breastplate-oracle (Antiquities III.8.9) as an additional
  functional parallel.
- A "Sea North/Sea South" cardinal-direction analysis and a "Sea of the
  West" cartographic thread for the Book of Mormon's four-seas geography
  (the dossier itself concedes the geometry is structurally *inverse*, not
  a match — an honest negative finding).
- A Rigdon-Pittsburgh chronology chapter.
- Ethan Smith's *View of the Hebrews* and Jonathan Carver's *Travels*
  (confirmed by the dossier to lack the compass-as-spirit passage,
  narrowing that specific claim to Lahontan specifically).
- A skeptical, detailed treatment of the Spalding-Rigdon theory itself
  (the recovered Oberlin manuscript is "general and superficial"
  resemblance only; the theory's "there must have been a second,
  now-lost manuscript" rescue hypothesis is flagged as a textbook
  conjunction fallacy).
- A "Romance of Celes" archival item explicitly flagged by the dossier as
  a probable source-conflation trap, **not** usable as evidence.
- Real archival-inquiry letter drafts (to Dartmouth, the Library Company
  of Philadelphia, Monticello) for further primary-source verification.

None of this has been independently re-verified by this codebase yet —
it's recorded here as a map of what exists and where, not re-validated
findings. Treat it as the next layer of work, not settled.

## Future work / open threads

- **Acquire the material still missing**: the user's dossier's own next
  concrete step — none of the above secondary threads (Josephus, Sea of
  the West, View of the Hebrews text itself) are in this repo's corpus yet.
- **A proper Burrows' Delta implementation** — a GitHub tools survey found
  no actively-maintained pure-Python implementation worth the dependency
  (`pydelta` is stagnant with an ambiguous license; `faststylometry` pulls
  in pandas). The R package `stylo` is the field standard; worth reading
  its methodology to align this toolkit's cosine-similarity approach with
  the peer-reviewed Delta formula even without adopting the R dependency.
- **`bcbooks/scriptures-json`** (GitHub, verse-tagged Book of Mormon JSON,
  public-domain-sourced) could replace `segmenter.py`'s regex-based parser
  with authoritative verse-tagged data — not urgent since the regex parser
  is now tested and self-checking, but worth it if higher confidence in
  chapter/verse attribution is ever needed.
- **Jockers, Witten & Criddle (2008)** — the one prior academic
  computational "wordprint" study of this exact authorship question
  (Spalding-Rigdon, tested via Nearest Shrunken Centroid classification).
  Data is on the Stanford Digital Repository (no public code). Worth
  pulling directly to sanity-check this toolkit's results against the most
  legitimate prior computational study of the same hypothesis, and against
  the BYU rebuttal (Fields, Schaalje & Roper 2011) that critiqued its
  methodology.
- **Mosiah-priority angle**: extend `by_dictation_batch` analysis to the
  onomasticon and namesim tools, not just raw term counts — e.g. does
  "Liahona"'s orthographic similarity to "Lahontan" look different if the
  comparison population is restricted to first-dictated-batch vocabulary
  only (closer to whenever "Liahona" was actually coined, if the
  Mosiah-priority reasoning above holds)?
- **The "Le Parasite Mormon" (1650)** French satire text itself was not
  acquired (likely requires Gallica/BnF archives) — the claim stays in
  `parody_hypotheses.py` with `source_acquired: false`.
